# `@hedera-commerce/sdk`

Private, server-side workspace package for the Hedera Commerce Rail SDK. See the repository [SDK guide](../../docs/sdk.md) for the public API, configuration, examples, security boundaries, and transaction semantics.

```ts
import { createCommerceClient } from "@hedera-commerce/sdk";
```

From the repository root: `npm run sdk:build`, `npm run sdk:check-types`, and `npm run sdk:test`. The package is not published to npm in M7.
